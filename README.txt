ESTEBAN NIEVES PORTFOLIO

OPEN THE WEBSITE
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.

ADD YOUR OWN PHOTOS
- Click “Add Photo” in the hero or either project card.
- Choose a JPG, PNG, or WEBP image.
- The website compresses and saves the image in that browser.
- Use “Change Photo” or “Remove” whenever needed.
- Photos saved this way stay only in the browser/device where you added them.

PERMANENT PHOTO METHOD FOR HOSTING
1. Put your image files inside the assets folder.
2. In index.html, find the photo section you want to edit.
3. Add an inline style such as:
   style="background-image: url('assets/my-go-kart.jpg')"
4. Add the class has-photo to that same element.

OTHER EDITS
- Replace each LinkedIn # link in index.html with your real LinkedIn URL.
- Edit any text directly in index.html.
- Your resume is already included as ESTEBAN_NIEVES_Resume.pdf.

PUBLISHING
Upload the entire folder to GitHub Pages, Netlify, Vercel, or another static website host.
